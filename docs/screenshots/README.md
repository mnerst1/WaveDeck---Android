# Actual-app screenshots

These PNG files are captured from WaveDeck on the installed Android 17 Pixel 10a emulator. The cover shown is WaveDeck's original vector illustration; the selected track is its locally synthesized demo. No external music artwork or mockup is used.

The app's Classic, Material Expressive and Liquid Glass compositions are separate layouts. Device status/navigation bars are part of the capture. Screenshot resolution is 1080 × 2424.
